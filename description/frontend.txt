
MODULE 6: STREAMLIT FRONTEND
6.1 Architecture & User Experience Design
Goal: Create an intuitive interface that clearly demonstrates the value of the knowledge graph.
Navigation Structure:

Home/Dashboard - Overview, statistics, quick insights
News Search - Search articles with BM25
Knowledge Graph - Interactive graph visualization (THE CENTERPIECE)
Analytics - PageRank and Community Detection results
Trends - Time-series analysis of relationships

6.2 Visualization Strategy for Meaningful Graph Display
Critical for demonstrating value:
Visual Design Principles:

Node sizing - Size nodes by importance (PageRank score or degree)
Node coloring - Color by entity type (Company=blue, Person=green, etc.)
Edge styling - Different colors/styles for relationship types
Labels - Show entity names clearly, make them readable
Layout - Use force-directed layout for natural clustering
Interactivity - Click nodes to see details, hover for information

PyVis Configuration for Maximum Impact:

Enable physics simulation for dynamic layout
Set appropriate repulsion/attraction forces
Add node hover tooltips with entity details
Add edge hover tooltips with relationship type and evidence
Enable node dragging for manual arrangement
Set appropriate canvas size (1000x700 pixels minimum)

To make it "meaningful":

Highlight key players (largest nodes with labels)
Show relationship diversity through colors
Create visual clusters (communities should group together naturally)
Add legend explaining node colors and sizes
Include statistics panel next to graph

File: frontend/components/graph_visualizer.py
Purpose: Reusable graph visualization component
Create function create_interactive_graph(nx_graph, config_options):
Parameters:

nx_graph: NetworkX graph object
config_options: Dictionary with visualization settings

node_size_by: str
color_scheme: dict
show_labels: bool
physics_enabled: bool
width: str
height: str



Implementation requirements:

Create PyVis Network object:

   from pyvis.network import Network
   net = Network(height=height, width=width, directed=True)

Configure physics:

   net.set_options("""
   {
     "physics": {
       "enabled": true,
       "forceAtlas2Based": {
         "gravitationalConstant": -50,
         "centralGravity": 0.01,
         "springLength": 200
       }
     }
   }
   """)

Add nodes from NetworkX graph:

For each node, calculate size based on config (PageRank, degree, etc.)
Assign color based on entity type
Add hover tooltip with entity details
Add node to PyVis network


Add edges from NetworkX graph:

For each edge, get relationship type
Assign color based on relationship type
Add hover tooltip showing relationship and evidence
Set edge width based on frequency (more mentions = thicker edge)


Generate HTML:

Call net.generate_html()
Return HTML string


Display in Streamlit:

Use components.html(html_string, height=height)



Styling requirements:

Node colors by entity type:

Company: #1f77b4 (blue)
Person: #2ca02c (green)
Product: #ff7f0e (orange)
Organization: #d62728 (red)
Location: #9467bd (purple)


Node size calculation:

If size_by == "PageRank": size = pagerank_score * 1000
If size_by == "Degree": size = degree * 10
Minimum size: 10, Maximum size: 50


Edge colors by relationship type:

acquires: red
partners_with: green
invests_in: gold
supplies_to: blue
competes_with: orange
Default: gray



Make it look professional:

Smooth edges
Appropriate spacing
Clear labels (only show for important nodes)
Responsive to interactions
