BM25 Formula:
BM25(D, Q) = Σ IDF(qi) × (f(qi, D) × (k1 + 1)) / (f(qi, D) + k1 × (1 - b + b × (|D| / avgdl)))
Where:

D = document (article)
Q = query
qi = each term in the query
f(qi, D) = frequency of term qi in document D
|D| = length of document D (number of words)
avgdl = average document length across all documents
k1 = 1.5 (tuning parameter, leave as constant)
b = 0.75 (tuning parameter, leave as constant)
IDF(qi) = log((N - n(qi) + 0.5) / (n(qi) + 0.5) + 1)
N = total number of documents
n(qi) = number of documents containing term qi

Implementation will be step-by-step below.

Text Preprocessing for Financial Text
Special requirements for financial text:

Preserve stock tickers: $AAPL, $GOOGL, $TSMC
Preserve percentages: 15%, 3.5%
Preserve currency amounts: $100M, €50B
Preserve company suffixes: Inc., Co., Ltd., Corp.

Preprocessing steps:

Tokenization (split on whitespace and punctuation, but preserve special patterns)
Normalization (lowercase, but keep stock tickers as-is)
Stop word removal (but keep negations: "not", "no", "never")
Stemming (Porter Stemmer)

pythonfrom collections import defaultdict, Counter

for article in articles:
    doc_id = article['article_id']
    text = article['headline'] + " " + article['full_text']
    tokens = self.preprocessor.preprocess(text)

__init__(self, inverted_index, k1=1.5, b=0.75):

Store reference to InvertedIndex instance
Store BM25 parameters: k1 and b

calculate_idf(self, term):

Calculate IDF score for a term
Formula: IDF(term) = log((N - n(term) + 0.5) / (n(term) + 0.5) + 1)
Where:

N = self.inverted_index.num_docs
n(term) = self.inverted_index.get_document_frequency(term)


Use math.log() for logarithm
Return IDF score

calculate_bm25_for_document(self, query_terms, doc_id):

Calculate BM25 score for a single document given query terms
Initialize score = 0
For each term in query_terms:

Get IDF for this term
Get term frequency in this document (search through postings list)
If term not in document, skip
Get document length: doc_length = self.inverted_index.doc_lengths[doc_id]
Calculate BM25 component:



python    numerator = term_freq * (self.k1 + 1)
    denominator = term_freq + self.k1 * (1 - self.b + self.b * (doc_length / self.inverted_index.avg_doc_length))
    score += idf * (numerator / denominator)

Return final score

score_all_documents(self, query_terms):

Score all documents that contain at least one query term
Steps:

Find all documents that contain any query term
For each document, calculate BM25 score
Return dictionary: {doc_id: score}



How to find all relevant documents:
pythonrelevant_docs = set()
for term in query_terms:

        relevant_docs.add(doc_id)
